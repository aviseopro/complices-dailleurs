# Modifier le site sans coder

1. Ouvrez `/admin` et entrez le mot de passe.
2. **Inscriptions** : suivre les pré-réservations/réservations, marquer *Payé*, *Annuler*, *Rembourser*, ouvrir le journal des statuts, **Exporter en CSV**.
3. **Expériences** : pour chaque séjour — statut (Ouverte / Liste d’attente / Bientôt), tarif, pré-réservation (35 €), capacité, durée, hébergement, lieu, présentation, inclus / non inclus, programme jour par jour, conditions, **dates et quotas**. Laissez vide ce qui n’est pas confirmé : le site affiche « À confirmer ».
4. **FAQ & avis** : modifier la FAQ ; ajouter uniquement de vrais témoignages (la section n’apparaît que s’il y en a).
5. **Réglages** : mode démo, activation de la vente Marrakech, Alma, image du hero, Instagram, email, politique d’annulation.

⚠️ Ne désactivez le *mode démo* et n’activez la vente Marrakech/Alma qu’après validation juridique (vente de voyages à forfait, garantie financière, assurance, CGV) et intégration réelle du paiement.
⚠️ Dans cette version de démonstration, les modifications restent dans votre navigateur. Pour que les deux organisatrices partagent les mêmes données, le back-end décrit dans `DEPLOIEMENT.md` est nécessaire.
